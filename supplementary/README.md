# Supplementary materials

Extended results and supporting analyses not covered in the main manuscript.

| File                              | Content                                             |
|-----------------------------------|-----------------------------------------------------|
| `supp_s1_derivations.pdf`         | Full proofs of Proposition 1, 2 and Theorem 1       |
| `supp_s2_full_baseline_grid.csv`  | Per-baseline hyperparameter grid and selections     |
| `supp_s3_full_topk_edges.csv`     | Complete top-K edge list behind Fig. 5              |
| `supp_s4_motion_sensitivity.md`   | Motion-filtering sensitivity analysis               |
| `supp_s5_demographic_tables.csv`  | Age / sex breakdown by site                         |
| `supp_s6_variance_decomp.md`      | Variance decomposition of block representations     |
| `supp_s7_runtimes.csv`            | Wall-clock per fold for every baseline              |
| `supp_s8_seed_sweep.csv`          | Repeat-to-repeat variance for FIDES over 10 seeds   |

See `supplementary/scripts/` for the scripts that regenerate each file.
